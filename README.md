# Fantime Exchange Bot — v2 (настройка полностью через телеграм)

## Что изменилось
- Все игровые настройки (host, port, ник аккаунта, координаты, цена сферы) хранятся в БД
  и задаются командами `/setup` в админ-боте — редактировать файлы на сервере не нужно.
- Капча теперь приходит **картинкой** (скриншот вьювера через puppeteer), а не только текстом.

## Установка (один раз через SSH)

```bash
npm install
cp .env.example .env
nano .env   # впиши ТОЛЬКО секреты: ADMIN_BOT_TOKEN, ADMIN_WHITELIST, DEPOSIT_BOT_TOKEN, GAME_BOT_API_TOKEN
```

### Chromium для скриншота капчи

```bash
apt install -y chromium
which chromium   # обычно /usr/bin/chromium — впиши в CHROME_PATH в .env, если путь другой
```

### Запуск через PM2

```bash
npm i -g pm2
pm2 start src/depositBot.js --name mc-game-bot
pm2 start src/adminBot.js --name mc-admin-bot
pm2 start src/depositClientBot.js --name mc-deposit-bot
pm2 save
pm2 startup   # выполнить команду, которую пропишет pm2
```

## Дальше — вся настройка в телеграме

Пиши своему **админ-боту** (не клиентскому):

```
/setup host play.fantime.example
/setup port 25565
/setup username ИмяАккаунтаБота
/setup auth microsoft
/restart_game        (напомнит выполнить pm2 restart mc-game-bot на сервере)
```

Дождись пока подключится, потом:

```
/setup coord chest 100 64 200
/setup coord anvil 101 64 200
/setup coord shulker 102 64 200
/setup sphere_price 80000000
```

Проверить всё разом:
```
/config
/status
```

## Как это работает

- `mc-game-bot` (`depositBot.js`) при старте **ждёт**, пока в БД не появятся `mc_host` и
  `mc_username` — можно спокойно запускать его через PM2 даже без настройки, он просто будет
  висеть в ожидании и раз в 5 сек проверять конфиг.
- Координаты и цену сферы можно менять на лету — рестарт игрового бота не требуется, они
  читаются из БД перед каждой операцией.
- Смена host/port/username/auth требует `pm2 restart mc-game-bot` — это разрыв текущего
  соединения, поэтому вручную, чтобы не оборвать бота посреди операции.

## Команды админ-бота

| Команда | Что делает |
|---|---|
| `/setup` | список всех команд настройки |
| `/config` | показать текущие настройки |
| `/status` | подключён ли игровой бот к серверу |
| `/ah sell <цена>` | выставить лот |
| `/ah search <ник>` | найти лоты игрока |
| `/captcha_ok <id> <текст>` | ответить на капчу (придёт картинкой с подписью) |
| `/deposit_run <id>` / `/withdraw_run <id>` | вручную дёрнуть обработку заявки |
| `/stats` | сколько заявок в очереди/провалилось |

Доступ только для `telegram_id` из `ADMIN_WHITELIST` в `.env`.

## Заглушки, которые всё ещё нужно доделать под конкретно Фантайм

1. **Формат капчи** — `CAPTCHA_REGEX` в `depositBot.js` ловит по тексту в чате. Если капча через
   GUI-окно, а не чат — нужно перехватывать `windowOpen`, а не `message`.
2. **Парсинг лора аукциона** — `extractSellerFromLore` / `extractPriceFromLore` в `depositBot.js`.
   Формат лора у каждого сервера свой, один раз залогируй реальный `item.nbt` лота и подгони regex.
3. **Переименование через наковальню** — если `bot.openAnvil().rename()` не сработает под протокол
   сервера, переименование делается вручную через `clickWindow` в текстовое поле окна.

## Безопасность

- Порт вьювера (3007) закрой файрволом от посторонних — картинка игры не должна быть публичной:
  `ufw allow from <твой_IP> to any port 3007 && ufw enable`
- Перед покупкой лота на вывод бот сверяет ник продавца и цену со значением из заявки — не убирай
  эту проверку.
- `.env` никому не показывай, токены дают полный контроль над ботами.
